## Hey, I'm starlordz12 👋

I design and 3D-print RC aircraft, build AI-assisted tooling for flight controllers and CAD, and self-host most of what I run on a Raspberry Pi cluster.

### 🛠️ What I work on

- **RC aircraft & UAVs** — 3D-printable planes, EDF jets, flying wings, and thrust-vectoring nozzles, modeled in Blender / OpenVSP.
- **Flight-controller tooling** — conversational setup and diagnostics for iNAV fixed-wing boards.
- **AI-assisted CAD & MCP servers** — Model Context Protocol servers that let Claude drive Blender, mesh editing, and hardware workflows.
- **Homelab & self-hosting** — Docker-first, Tailscale-only infrastructure-as-code on a Raspberry Pi 5.

### 📌 Selected projects

| Project | What it is |
| --- | --- |
| [inav-mcp](https://github.com/starlordz12/inav-mcp) | MCP server for setting up, diagnosing, and tuning iNAV flight controllers over USB — driven through Claude. |
